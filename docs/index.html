🥏 Live! by BULA Spirit Director

Spirit of the Game information for spirit directors, drawn from the Live! by BULA API.

View on GitHub
This is an unofficial tool and is not endorsed by BULA, WFDF, EUF or UltiOrganizer. Expect things to move and break.

Why?

Live! by BULA is an interface primarily designed for players and spectators. As a volunteer in the Spirit Team at WUCC 2026 I found that I wanted the information displayed in a slightly better way. This is an attempt to show some more information to be useful at future tournaments.

This project is very limited because it can only show publically available information (no spirit comments or partially completed spirit for a game) and because I have chosen GitHub Pages it must be stateless with no persistance of data. Presistance of data would allow the spirit team to highlight games of interest and keep tracking notes on status and actions taken.

How?

This site reads the same public JSON files Live! uses for its own front end. For working and demonstration purposes it can also use archived results from ultimate-tournament-results , which serves the same files.

The site is simple static HTML and JavaScript (typed with JSDoc) built from that dynamic content and served with GitHub Pages.

Response shapes differ between Live! versions, see live-by-bula-openapi. Each supported version has its own adapter so that tournaments can be continually supported.
